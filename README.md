## Featured Project — WAY

**肩書きではなく、会話からつながる匿名チャットアプリ。**

短い「声」を投稿し、気になった声に反応することで、知らない誰かとの1対1の会話が始まるサービスです。コードネームで会話する、開発中のプロトタイプです。

**Tech:** Next.js / TypeScript / Supabase / PostgreSQL / Realtime

**担当:** 企画・仕様設計・デザイン判断・動作確認。コード実装やテスト作成では主に生成AIを活用しています。

現在は開発・検証段階。検証環境でログイン・ホーム表示を確認済みです。API認可やAI審査の改善はDraft PRでレビュー中・main未反映。AI審査はモックで検証し、実APIは呼び出していません。

[WAYのGitHubリポジトリ](https://github.com/Uni681/way-app) | [開発・改善の記録](https://github.com/Uni681/way-app/pull/1)

## How I Build

- **Problem First** — 技術を選ぶ前に、解決したい課題と体験を考える
- **AI Collaboration** — 生成AIと役割を分担し、アイデアを形にする
- **Iterative Improvement** — 実際に動かし、検証しながら改善する
- **Operational Thinking** — エラー、権限、運用コストまで考える
